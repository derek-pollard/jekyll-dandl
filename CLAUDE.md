# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Serve locally with live reload
bundle exec jekyll serve

# Build only
bundle exec jekyll build

# Include draft posts in local serve
bundle exec jekyll serve --drafts
```

The site is deployed to GitHub Pages automatically on push to `master`. The `CNAME` file sets the custom domain.

## Architecture

This is a Jekyll 4.3 site migrated from WordPress. There are no plugins — all logic is in Liquid templates.

### Page hierarchy and the `template` pattern

The `layout: page` layout delegates rendering to an include named by the page's `template` front matter variable (`_layouts/page.html`). This means the same Jekyll layout handles several visually distinct page types:

| `template` value | Include used | Purpose |
|---|---|---|
| `rootcategorypage` | `_includes/rootcategorypage.html` | Top-level section (e.g. `/pets/`) |
| `parentcategorypage` | `_includes/parentcategorypage.html` | Mid-level section listing child categories (e.g. `/pets/cats/`) |
| `categorypage` | `_includes/categorypage.html` | Leaf category page — renders all matching posts inline |
| `homepage` | `_includes/index.html` | Homepage (also uses `layout: home`) |

### How posts appear on category pages

Posts live in `_posts/` and are **not** rendered as standalone pages — they have `layout: post` but the `categorypage` include iterates `site.posts` and inlines them directly onto their parent category page. The link between a post and its category page is `category-slug` in the post's front matter matching `page-slug` in the category page's front matter.

On the homepage (`_layouts/home.html`), the 15 most recent posts are shown as thumbnails in the "What's new" section. Each thumbnail links to an anchor on the category page, generated by `_includes/postidtoanchor.html` (which converts the post's file path to an anchor id like `post--posts-2024-...`).

### Colour theming

Each section has a `banner-colour` in its front matter (e.g. `'#29bd8c'` for Cats). `_includes/header.html` reads this and emits an inline `<style>` block that overrides heading and link colours for the entire page. Child pages inherit the colour from their parent via the `parent-slug` → `banner-colour` lookup in `header.html`.

### Content structure

- **Pages** live in the directory they're served from (`pets/cats/inkie.md` → `/pets/cats/inkie/`)
- **Posts** all live flat in `_posts/` regardless of category, named `YYYY-MM-DD-slug.md`
- **Images** live under `images/` (site assets) and `wp-content/uploads/` (migrated WordPress media — organised by year/month)

### Key front matter fields

| Field | Used on | Purpose |
|---|---|---|
| `page-slug` | pages | Unique identifier used to match posts and child pages |
| `parent-slug` | pages | Links a page to its parent for colour inheritance and diary navigation |
| `category-slug` | posts | Matches `page-slug` of the category page the post belongs to |
| `page-order` | pages | Sort order within `parentcategorypage` listings (reversed — higher = shown first) |
| `summary-image` / `summary-text` / `summary-title` | pages | Used by `parentcategorypage` to build category grid cards |
| `thumbnail` | posts | Small image shown in homepage "What's new" strip |
| `date-range` | pages | Human-readable date string shown on category pages |

### Includes reference

- `captionedimage.html` — WordPress-style `wp-caption` div; params: `align`, `width`, `height`, `src`, `alt`, `title`, `caption`
- `vimeovideo.html` — Vimeo embed; param: `videoid`
- `diarynavigation.html` — prev/next navigation for diary-style sub-pages ordered by `page-order` within a `parent-slug`
- `subnavigation.html` — hardcoded secondary nav shown on pet category pages
